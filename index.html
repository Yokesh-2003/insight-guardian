How It Works

                    

                        

                            
01

                            

                                
File Upload & Hashing

                                
Files are securely uploaded and a SHA-256 hash is computed for signature matching.

                            

                        

                        

                            
02

                            

                                
Signature Scanning

                                
Hash comparison against known malware database and RegEx pattern matching for suspicious strings.

                            

                        

                        

                            
03

                            

                                
ML Analysis

                                
Deep Autoencoder extracts features (byte frequency, entropy) and computes reconstruction error.

                            

                        

                        

                            
04

                            

                                
Verdict Generation

                                
Results are aggregated with confidence scores and detection method attribution.
